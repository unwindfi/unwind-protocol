Ticker logos, generated by `npx ts-node scripts/gen-logos.ts`.

Apple, NVIDIA and Tesla marks come from `simple-icons`, whose icon files are
CC0. The trademarks themselves belong to their owners; this is a local demo, and
shipping it anywhere real is a question for whoever owns that deployment. SPY is
an ETF with no icon in the set, so it gets a drawn index mark.

To override any of them, replace `<SYMBOL>.svg` — the UI loads whatever is here
and falls back to a monogram in the brand colour if a file is missing.

The Solana tokens (`SOL`, `BONK`, `WIF`, `JUP`, `PYTH`, `JTO`, `RAY`, `BOME`,
`MEW`, `POPCAT`, `PENGU`, `TRUMP`, `FARTCOIN`, `ORCA`, `WEN`, `RENDER`, `HNT`,
`PUMP`, `MOODENG`, `AI16Z`, `JLP`, `DRIFT`) are the artwork each
token's own metadata points at, fetched by mint through Jupiter's token registry
(with CoinGecko and DexScreener as fallbacks for the ones whose gateways
rate-limit), converted to PNG and capped at 256px. Same caveat: the marks belong
to their projects. `BTC` and `ETH` are the plain coin marks from CoinGecko rather
than the Wormhole-wrapped ones the Solana registry carries, since the page is
naming the asset, not the bridge.
